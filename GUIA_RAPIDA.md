# 🚀 GUÍA RÁPIDA - Instalación desde iPhone

## ⏱ Tiempo total: 5-7 minutos

---

## 📱 MÉTODO MÁS FÁCIL: App GitHub

### Paso 1: Prepara la app GitHub (2 min)
```
1. App Store → Busca "GitHub"
2. Descarga la app oficial
3. Abre → Inicia sesión
```

### Paso 2: Crea repositorio (1 min)
```
4. Toca + (arriba derecha)
5. New repository
6. Nombre: expediente-anestesico
7. Visibility: Public ← IMPORTANTE
8. Create repository
```

### Paso 3: Sube archivos (2 min)
```
9. Add file → Upload files
10. Selecciona los 6 archivos:
    ✓ index.html
    ✓ manifest.json
    ✓ sw.js
    ✓ icon-192.png
    ✓ icon-512.png
    ✓ apple-touch-icon.png
11. Commit changes
```

### Paso 4: Activa GitHub Pages (1 min)
```
12. Settings (engranaje abajo)
13. Pages (menú lateral)
14. Source → Branch: main
15. Save
16. Espera 2 min → Copia la URL que aparece
```

### Paso 5: Instala en iPhone (1 min)
```
17. Safari → Pega tu URL
18. Compartir ⎙ (botón central inferior)
19. Desplázate → "Añadir a pantalla de inicio"
20. Añadir
```

---

## 🎉 ¡TERMINADO!

### ✅ Verificar que funciona:
1. Busca el ícono en tu pantalla de inicio
2. Abre la app
3. Activa Modo Avión
4. La app sigue funcionando ← Si funciona, todo OK

---

## 🆘 Si algo falla:

### "No encuentro Pages en Settings"
→ Verifica que el repositorio sea **Public** (no Private)

### "La app no funciona sin internet"
→ Espera 3 minutos más después de activar Pages

### "No aparece el botón 'Añadir a pantalla de inicio'"
→ DEBES usar Safari (no Chrome ni otro navegador)

---

```
https://[tu-usuario-github].github.io/expediente-anestesico/
```
