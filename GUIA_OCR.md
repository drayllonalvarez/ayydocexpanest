# 📷 GUÍA - Sistema de Escaneo OCR Multi-Página

## 🎯 ¿QUÉ HACE?

Escanea **hasta 3 páginas** de valoraciones preanestésicas y automáticamente:
✅ Extrae datos demográficos del paciente  
✅ Extrae laboratorios completos  
✅ Extrae exploración física  
✅ Extrae signos vitales  
✅ Extrae ECG y Rx tórax  
✅ Rellena consentimiento + valoración  
✅ Ahorra 10-15 minutos por paciente  

---

## 📱 CÓMO USAR (MULTI-PÁGINA)

### **Paso 1: Abre el escáner**
```
Toca el botón 📷 (flotante en esquina inferior derecha)
```

### **Paso 2: Captura TODAS las páginas**

**Opción A: Cámara (una por una)**
```
1. Toca "📷 Cámara"
2. Toma foto de la primera página
3. Toca "➕ Agregar otra página"
4. Toma foto de la segunda página
5. Repite hasta 3 páginas máximo
```

**Opción B: Galería (múltiples)**
```
1. Toca "🖼️ Galería"
2. Selecciona TODAS las fotos (hasta 3)
3. El sistema las carga automáticamente
```

### **Paso 3: Revisa las páginas**
```
Verás miniaturas de todas las páginas capturadas
Puedes eliminar cualquiera con el botón ×
```

### **Paso 4: Extrae los datos**
```
1. Toca "✨ Extraer datos de todas las páginas"
2. Espera mientras procesa (30-90 segundos para 3 páginas)
3. Verás progreso: "Página 1/3... 50%"
```

### **Paso 5: Aplica los datos**
```
1. Revisa TODOS los datos extraídos
2. Toca "✓ Aplicar datos a los formularios"
3. Los formularios se rellenan automáticamente
```

## 💡 TIPS PARA MÚLTIPLES PÁGINAS

### **1. Orden de captura** 📄
```
Página 1: Datos generales + signos vitales
Página 2: Laboratorios + ECG + Rx
Página 3: Exploración física completa
```

### **2. Calidad consistente** ✨
```
✅ Misma iluminación en todas
✅ Mismo ángulo
✅ Sin sombras ni reflejos
```

### **3. Documentos separados** 📑
```
✅ No captures múltiples hojas juntas
✅ Una foto = una página
✅ Máximo 3 páginas por sesión
```

```

→ Revisa especialmente laboratorios
```

```
1. Elimina esa página (botón ×)
2. Vuelve a capturarla con mejor calidad
3. O ingresa esos datos manualmente
```

### **Límites:**
```
✅ Máximo 3 páginas por sesión
✅ Si tienes más, haz 2 sesiones
✅ Primera sesión: páginas 1-3

```

## 🆘 SOLUCIÓN DE PROBLEMAS

### ❌ "No se pueden agregar más páginas"
```
Límite: 3 páginas máximo
Solución: Procesa las 3 primeras, luego ingresa resto manualmente
```

### ❌ "El procesamiento es muy lento"
```
Causa: 3 páginas = 3× tiempo de procesamiento
Solución: Espera pacientemente o usa menos páginas
Tiempo esperado: ~30 seg por página
```

### ❌ "Datos mezclados entre páginas"
```
Causa: Sistema combina texto de todas las páginas
Solución: Normal. Revisa y organiza los datos extraídos
```

### ❌ "Falta información de una página"
```
Causa: Esa página era ilegible
Solución: Vuelve a capturar solo esa página
O ingresa manualmente los datos faltantes
```
